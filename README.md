# rubiks_solver

Minimal skeleton Python package for Rubik's Cube solver utilities.

Quick start

- Create a virtualenv and install dev dependencies:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .[dev]
```

- Run tests:

```bash
pytest -q
```

Package modules:

- `rubiks_solver.perm` — simple permutation classes (stubs).
- `rubiks_solver.cli` — small CLI entrypoint.
